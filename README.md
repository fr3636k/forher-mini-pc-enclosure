# 豐禾｜超音波錄影盒 3D 設計展示

V1.1，小螢幕版本。程式不使用病人資料，也不連接實際讀卡機或錄影服務。

## 使用

- 線上展示網址見 `LIVE-URL.txt`（發布完成後提供）。
- 滑鼠拖曳旋轉、滾輪縮放；手機以單指旋轉、雙指縮放。
- 四個視圖：整體外觀、操作座特寫、內部拆解、側掛位置。
- 「拆開盒蓋」滑桿可查看前蓋、上蓋與螢幕背面固定方式。
- 待機、插卡錄影、拔卡存檔按鈕僅模擬流程；時間為固定展示值。
- 「下載 3D 模型」會匯出目前螢幕狀態的組合模型（GLB、已組裝）。

## 本機執行

在此資料夾開啟 PowerShell，執行 `./start-preview.ps1`，或使用 Node.js 執行：

```powershell
node serve.mjs
```

然後開啟 <http://127.0.0.1:8787>。不需要 npm install。不要直接雙擊 HTML，瀏覽器對本機 ES modules 的限制可能讓模型無法載入。

## 部署到其他網站

- 靜態網站成品在 `dist/`，包含網頁、3D 程式及所有必要 Three.js 檔案，不依賴外部 CDN。
- Netlify 手動部署：將 `dist` 資料夾拖入部署區。
- Git 部署：已附 `netlify.toml`，發布資料夾為 `dist`，不需建置指令。
- 可攜檔案 `ultrasound-3d-web.zip` 只包含 `dist` 內容，解壓後即可上傳一般靜態主機。

## 尺寸與版本

單位：模型幾何以 mm 建立，GLB 匯出時轉換成 m。

- 主機盒：寬 300 × 深 280 × 高 160，板厚 12。
- 小螢幕操作座：寬 200 × 深 160 × 高 120，板厚 9。
- 主機占位：寬 180 × 深 180 × 高 80。
- 螢幕：3.5 吋級占位示意，非指定型號的實際外殼尺寸。
- 與原先七段顯示器 PDF 的操作座尺寸不同；本版已明確改為小螢幕版本。
- 木板尺寸不包含外加腳墊、螺絲、讀卡機、卡片或掛架的突出部分。

## 製作界線

本模型用來看外觀、配置與維修方式，不是 CAD 施工圖、STEP 實體或可直接 3D 列印的封閉模型。

主機與螢幕尚未選型，因此固定孔、實際支架、線材出口、風道及加工公差仍需量測。推車外形與掛架僅為情境示意，並不代表已通過承重或醫療設備相容性確認。變壓器應另設通風固定位置。

後續可修改 `model.js` 的各個 block/panel 尺寸與位置，再依實物完成木工圖。
